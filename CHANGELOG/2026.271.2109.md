## Summary

The `cachyos-extras` candy repo declared **no `skill:` entity**, so no owning
`/charly-distros:cachyos-extras` skill was projected and the repo's `AGENTS.md` R0 list
had no owning skill to name (#291).

across the corpus (`ripgrep-skill:`, `nvidia-skill:`, `supervisord-skill:`,
`yay-skill:`, `kind-skill:`). This adds `cachyos-extras-skill:` as a new top-level
node in `charly.yml`.
